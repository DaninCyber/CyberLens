# CyberLens

CyberLens is an open-source cybersecurity platform focused on making security simple, understandable and actionable.

## Vision

CyberLens helps users understand the security of their devices without requiring expert knowledge.

## Current Status

🚧 Version 0.1.0

Currently under active development.

## Planned Features

- Local security scanning
- Security scoring
- Vulnerability checks
- Network discovery
- Home lab management
- Threat intelligence

## Tech Stack

- Python
- FastAPI
- React
- TypeScript
- SQLite
